# React Nanodegree — Exercises

Hands-on exercises I completed while working through the React Nanodegree. Each folder is a standalone Create React App project with its own `instructions.md` describing the task, so you can see the problem and my solution side by side.

![React](https://img.shields.io/badge/React-20232A?logo=react&logoColor=61DAFB)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## Exercises

| # | Exercise | Concepts practised |
| - | -------- | ------------------ |
| 1 | [Passing data](excercise-1-passing-data) | Rendering lists from related data objects (people ↔ favourite books), props |
| 2 | [Passing data II](excercise-2-passing-data) | Inverting the data relationship, splitting UI into reusable components, conditional rendering |
| 4 | [Managing state](excercise-4-managing-state) | "Add the numbers" game – component state, event handlers, score tracking |
| 5 | [Controlled components](excercise-5-controlled-component) | Controlled form inputs that mirror typed text |
| 6 | [All topics I](excercise-6-all-topic-component-1) | Refactoring a working app into modular, stateless + stateful components |
| 7 | [All topics II](excercise-7-all-topic-component-2) | Add users via a form and list games played, with a show/hide toggle for the count |
| 8 | [All topics III](excercise-8-all-topic-component-3) | A second, refactored solution to the exercise 7 task |

## Running an exercise

```bash
git clone https://github.com/darshan82/React-Nano-Degree-Tasks.git
cd React-Nano-Degree-Tasks/excercise-4-managing-state
npm install
npm start
```
